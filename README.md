## 🚀 What It Does
- Generates video scripts using Ollama + Llama3
- Creates AI voiceover using Coqui TTS
- Auto generates subtitles using Whisper
- Creates YouTube thumbnail using Pillow
- Assembles final MP4 video using FFmpeg
- Fully automated end to end pipeline

## 🛠️ Tech Stack
| Tool | Purpose |
|------|---------|
| Ollama + Llama3 | Local AI script generation |
| Coqui TTS (VITS) | Open source voice generation |
| OpenAI Whisper | Speech to text subtitles |
| FFmpeg | Video assembly |
| Pillow | Thumbnail and slide creation |
| Python 3.10 | Core language |
